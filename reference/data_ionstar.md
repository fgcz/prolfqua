# IonStar peptide-level example data

Peptide intensities of 200 proteins from the IonStar human cell lysate
with E. coli spike-in dilution series (dilutions a to e, 4 replicates
each), processed with MaxQuant. An R6 object holding the data, its
[`AnalysisConfiguration`](https://wolski.github.io/prolfqua/reference/AnalysisConfiguration.md),
and the methods `filtered()`, `normalized()` and `subset_normalized()`.
See \`inst/script/README.md\` for its origin.

## Usage

``` r
data_ionstar
```

## Format

An R6 object of class \`IonstarData\`; \`\$data\` is a data frame with
26520 rows.

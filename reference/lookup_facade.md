# Look up a contrast facade by short name

Returns the registry entry of a method of
[`build_contrast_analysis()`](https://fgcz.github.io/prolfqua/reference/build_contrast_analysis.md),
including the input it needs (`"aggregated"` or `"nested"`).

## Usage

``` r
lookup_facade(name)
```

## Arguments

- name:

  short method name (e.g. `"lm"`, `"saint"`).

## Value

Registry entry list with at least `class`, `needs`, `package`,
`needs_saint_annotation`; or `NULL` if no entry exists.

# R6 class for limpa modelling strategy

R6 class for limpa modelling strategy

R6 class for limpa modelling strategy

## Value

An R6 class generator.

## Details

Consumed by
[`build_model_limpa`](https://wolski.github.io/prolfqua/reference/build_model_limpa.md).
Configures the
[`limpa::voomaLmFitWithImputation`](https://rdrr.io/pkg/limpa/man/voomaLmFitWithImputation.html)
call: formula for the design matrix, trend/robust flags for
[`eBayes`](https://rdrr.io/pkg/limma/man/ebayes.html), and optional
vooma plotting parameters.

## Public fields

- `formula`:

  model formula

- `model_name`:

  name of model

- `trend`:

  logical, passed to
  [`eBayes`](https://rdrr.io/pkg/limma/man/ebayes.html)

- `robust`:

  logical, passed to
  [`eBayes`](https://rdrr.io/pkg/limma/man/ebayes.html)

- `plot`:

  logical, plot the vooma mean-variance trend

- `span`:

  lowess smoother span for vooma trend (NULL = auto)

Create a new StrategyLimpa

      modelstr,
      model_name = "limpa",
      trend = FALSE,
      robust = FALSE,
      plot = FALSE,
      span = NULL
    )

#### Arguments

  model formula as string (e.g. "abundance ~ group\_")

  name of model

- `trend`:

  logical, passed to

  lowess smoother span (NULL = auto)

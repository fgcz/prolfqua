# Hurdle contrast facade for nested input

Hurdle contrast facade for nested input

Hurdle contrast facade for nested input

## Value

An R6 class generator.

## Details

Takes nested (peptide-level) LFQData and builds both hurdle components
internally: median polish to protein level and `lm_impute` on the
protein intensities, `binomial_firth_nested` on the peptide detection.
The two are combined with
[`ContrastsHurdleFacade`](https://fgcz.github.io/prolfqua/reference/ContrastsHurdleFacade.md).
Use `ContrastsHurdleFacade` directly to pair other intensity or
detection facades.

`get_missing()` reports against the median-polish protein data. The two
fitted models are `facade$contrast$intensity$model` and
`facade$contrast$detection$model`.

### Method `new()`

initialize

#### Usage

    ContrastsHurdleNestedFacade$new(lfqdata, modelstr, contrasts, ...)

#### Arguments

- `lfqdata`:

  nested LFQData (peptide-level, log2-transformed)

- `modelstr`:

  model formula string (e.g. "~ group\_")

- `contrasts`:

  named character vector of contrasts

- `...`:

  ignored; accepted for dispatch compatibility with other facades

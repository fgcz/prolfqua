## Public fields

- `model_df`:

  data.frame with modelling data and model.

- `model_name`:

  name of model

- `subject_id`:

  e.g. protein_Id

- `model_strategy`:

  function to create the models

- `anova_df`:

  function to compute anova

- `p.adjust`:

  function to adjust p-values

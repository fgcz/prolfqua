[`prolfqua::ModelInterface`](https://wolski.github.io/prolfqua/reference/ModelInterface.md)

## Public fields

- `modelDF`:

  data.frame with modelling data and model.

- `modelName`:

  name of model

- `subject_Id`:

  e.g. protein_Id

- `model_strategy`:

  function to create the models

- `anova_df`:

  function to compute anova

- `p.adjust`:

  function to adjust p-values

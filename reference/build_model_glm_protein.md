# Build Firth logistic model for aggregated LFQData

Encodes missingness as a binary response and fits the Firth logistic
backend used by the missingness model path in `prolfquapp`.

## Usage

``` r
build_model_glm_protein(lfqdata, modelstr, control = list())
```

## Arguments

- lfqdata:

  aggregated
  [`LFQData`](https://fgcz.github.io/prolfqua/reference/LFQData.md)
  object

- modelstr:

  model formula string without the response variable

- control:

  convergence controls, see
  [`strategy_logistf`](https://fgcz.github.io/prolfqua/reference/strategy.md)
  (e.g. `"~ group_"`)

## Value

a
[`ModelFirth`](https://fgcz.github.io/prolfqua/reference/ModelFirth.md)
object

``` r
istar <- sim_lfq_data_protein_config(
  n_proteins = 10, with_missing = TRUE, weight_missing = 0.5, seed = 3)
#> `protein_Id`: columns `proteinID`, `idtype2` united with separator '~'.
#> creating sampleName from file_name column
#> setup_analysis: dropped 5 unconfigured columns: average_prot_abundance, sd, mean, N, Replicate.
#> setup_analysis: added 23 rows with NA response for feature and sample combinations absent from the input.
lfqdata <- LFQData$new(istar$data, istar$config)
mod <- build_model_glm_protein(lfqdata, "~ group_")
```

# table facade to easily switch implementations

table facade to easily switch implementations

## Usage

``` r
table_facade(df, caption, digits = getOption("digits"), kable = TRUE)
```

## Arguments

- df:

  data.frame to display

- caption:

  table caption

- digits:

  number of digits (default from options)

- kable:

  if TRUE use knitr::kable

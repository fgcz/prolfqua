# Get group-level linear functions from a fitted model

Get group-level linear functions from a fitted model

## Usage

``` r
linfct_from_model(m, as_list = TRUE)
```

## Arguments

- m:

  linear model

- as_list:

  if TRUE, return the factor and interaction matrices as a list; if
  FALSE, as one matrix

## Value

if `as_list = TRUE`, a list with the matrices `linfct_factors` (one row
per factor level) and `linfct_interactions` (one row per observed factor
combination), each with one column per model coefficient; otherwise the
two matrices bound by rows into a single matrix

## Details

The fitted model supplies its coefficient names and observed categorical
factor combinations. Each combination is expressed as weights on the
fitted coefficients; weights for an individual factor level are averaged
equally over the observed combinations containing that level. Thus
`linfct_factors` describes marginal factor-level means and
`linfct_interactions` describes cell means. With treatment coding, a
reference-level mean includes the intercept; a non-reference mean also
includes its treatment coefficient. The *Under the hood* article shows a
complete `~ A * B` example. These helpers assume categorical predictors
and the usual intercept-based coding; they are not a general
marginal-means implementation for continuous predictors or arbitrary
coding.

## Examples

``` r
m <- sim_make_model_lm("factors")
#> `protein_Id`: columns `proteinID`, `idtype2` united with separator '~'.
#> creating sampleName from file_name column
#> setup_analysis: dropped 6 unconfigured columns: average_prot_abundance, sd, group, mean, N, Replicate.
linfct <- linfct_from_model(m, as_list = TRUE)

linfct$linfct_factors
#>             (Intercept) TreatmentB BackgroundZ
#> BackgroundX           1        0.5         0.0
#> BackgroundZ           1        0.5         1.0
#> TreatmentA            1        0.0         0.5
#> TreatmentB            1        1.0         0.5
linfct$linfct_interactions
#>                        (Intercept) TreatmentB BackgroundZ
#> TreatmentA:BackgroundX           1          0           0
#> TreatmentA:BackgroundZ           1          0           1
#> TreatmentB:BackgroundX           1          1           0
#> TreatmentB:BackgroundZ           1          1           1
lf <- matrix(
c(1, 1, 1, 1, 0.5, 0.5, 0, 1, 0, 1, 0.5, 0.5),
nrow = 4,
byrow = FALSE,
dimnames = list(c("BackgroundX", "BackgroundZ", "TreatmentA", "TreatmentB"),
                c("(Intercept)", "TreatmentB", "BackgroundZ"))
)
stopifnot(lf == linfct$linfct_factors)
m <- sim_make_model_lm("interaction")
#> `protein_Id`: columns `proteinID`, `idtype2` united with separator '~'.
#> creating sampleName from file_name column
#> setup_analysis: dropped 6 unconfigured columns: average_prot_abundance, sd, group, mean, N, Replicate.
linfct <- linfct_from_model(m)

m <- lm(Petal.Width ~ Species, data = iris)
linfct_from_model(m)
#> $linfct_factors
#>                   (Intercept) Speciesversicolor Speciesvirginica
#> Speciessetosa               1                 0                0
#> Speciesversicolor           1                 1                0
#> Speciesvirginica            1                 0                1
#> 
#> $linfct_interactions
#>                   (Intercept) Speciesversicolor Speciesvirginica
#> Speciessetosa               1                 0                0
#> Speciesversicolor           1                 1                0
#> Speciesvirginica            1                 0                1
#> 
xx <- data.frame( Y = 1:10 , Condition = c(rep("a",5), rep("b",5)) )
m <- lm(Y ~ Condition, data = xx)
linfct_from_model(m)
#> $linfct_factors
#>            (Intercept) Conditionb
#> Conditiona           1          0
#> Conditionb           1          1
#> 
#> $linfct_interactions
#>            (Intercept) Conditionb
#> Conditiona           1          0
#> Conditionb           1          1
#> 
xx <- data.frame( Y = 1:10 , Condition = c(rep("a",5), rep("b.b",5)) )
m <- lm(Y ~ Condition, data = xx)
linfct_from_model(m)
#> $linfct_factors
#>              (Intercept) Conditionb.b
#> Conditiona             1            0
#> Conditionb.b           1            1
#> 
#> $linfct_interactions
#>              (Intercept) Conditionb.b
#> Conditiona             1            0
#> Conditionb.b           1            1
#> 
xx <- data.frame( Y = 1:10 , Condition = c(rep("a",5), rep("ab",5)) )
m <- lm(Y ~ Condition, data = xx)
linfct_from_model(m)
#> $linfct_factors
#>             (Intercept) Conditionab
#> Conditiona            1           0
#> Conditionab           1           1
#> 
#> $linfct_interactions
#>             (Intercept) Conditionab
#> Conditiona            1           0
#> Conditionab           1           1
#>
```

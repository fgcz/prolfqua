# Create limma modelling strategy

Wrapper that returns a
[`StrategyLimma`](https://fgcz.github.io/prolfqua/reference/StrategyLimma.md)
R6 object.

## Usage

``` r
strategy_limma(
  modelstr,
  model_name = "limma",
  trend = FALSE,
  robust = FALSE,
  weights = NULL
)
```

## Arguments

- modelstr:

  model formula as string (e.g. "abundance ~ group\_")

- model_name:

  name of model

- trend:

  logical, passed to
  [`eBayes`](https://rdrr.io/pkg/limma/man/ebayes.html)

- robust:

  logical, passed to
  [`eBayes`](https://rdrr.io/pkg/limma/man/ebayes.html)

- weights:

  a column name (a sample annotation column gives per-sample weights, a
  value column such as `nr_children` gives a proteins x samples matrix),
  several value column names (their product), or a numeric matrix
  (proteins x samples) passed to
  [`lmFit`](https://rdrr.io/pkg/limma/man/lmFit.html). Default `NULL`
  (no weights).

## Value

a
[StrategyLimma](https://fgcz.github.io/prolfqua/reference/StrategyLimma.md)
object holding the formula, model name, `eBayes()` options and weights.

# Create limma modelling strategy

Wrapper that returns a
[`StrategyLimma`](https://fgcz.github.io/prolfqua/reference/StrategyLimma.md)
R6 object.

## Usage

``` r
strategy_limma(
  modelstr,
  model_name = "limma",
  trend = FALSE,
  robust = FALSE,
  weights = NULL
)
```

## Arguments

- modelstr:

  model formula as string (e.g. "abundance ~ group\_")

- model_name:

  name of model

- trend:

  logical, passed to
  [`eBayes`](https://rdrr.io/pkg/limma/man/ebayes.html)

- robust:

  logical, passed to
  [`eBayes`](https://rdrr.io/pkg/limma/man/ebayes.html)

- weights:

  either a character string (column name in annotation for per-sample
  weights) or a numeric matrix (proteins x samples) passed to
  [`lmFit`](https://rdrr.io/pkg/limma/man/lmFit.html). Default `NULL`
  (no weights).

## Value

The computed result.

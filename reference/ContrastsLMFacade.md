### Method `new()`

initialize

#### Usage

    ContrastsLMFacade$new(
      lfqdata,
      modelstr,
      contrasts,
      weights = lfqdata$nr_children_col(),
      ...
    )

#### Arguments

- `lfqdata`:

  LFQData object

- `modelstr`:

  model formula string (e.g. "~ group\_")

- `contrasts`:

  named character vector of contrasts

- `weights`:

  column name for per-observation weights (default:
  `lfqdata$nr_children_col()`). Pass `NULL` for unweighted.

- `...`:

  passed to
  [`strategy_lm`](https://fgcz.github.io/prolfqua/reference/strategy.md)

------------------------------------------------------------------------

### Method `clone()`

The objects of this class are cloneable with this method.

#### Usage

    ContrastsLMFacade$clone(deep = FALSE)

#### Arguments

- `deep`:

  Whether to make a deep clone.

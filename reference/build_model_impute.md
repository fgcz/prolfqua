# Build protein models with LOD imputation for failed fits

Fits per-protein models, then re-fits failed/singular proteins after
imputing missing values with the limit of detection (LOD) and clamping.
Covariance is borrowed from successful fits so that variance is not
underestimated by the constant imputation.

## Usage

``` r
build_model_impute(
  lfqdata,
  model_strategy,
  model_name = paste0(model_strategy$model_name, "Imputed"),
  lod = NULL,
  borrow_method = c("sigma", "vcov"),
  df_method = c("observed", "borrowed"),
  on_misalign = c("fallback", "fail")
)
```

## Arguments

- lfqdata:

  LFQData object (aggregated to protein level)

- model_strategy:

  model strategy object (e.g. from strategy_lm)

- model_name:

  model name (default appends "Imputed")

- lod:

  numeric limit of detection; if NULL, auto-computed from data

- borrow_method:

  "sigma" borrows scalar sigma and uses per-protein (X'X)^-1; "vcov"
  borrows element-wise median of full vcov matrices

- df_method:

  "observed" uses max(n_observed - p, 1); "borrowed" uses median df from
  successful fits

- on_misalign:

  passed to
  [`compute_borrowed_variance`](https://fgcz.github.io/prolfqua/reference/compute_borrowed_variance.md)
  via
  [`impute_refit_singular`](https://fgcz.github.io/prolfqua/reference/impute_refit_singular.md).
  "fallback" (default) preserves the lm behaviour; "fail" skips the
  rescue when a full covariance matrix cannot be borrowed (used by the
  rfit backend, which has no sigma-method fallback).

## Value

a object of class
[`Model`](https://fgcz.github.io/prolfqua/reference/Model.md)

## Examples

``` r
istar <- sim_lfq_data_protein_config(n_proteins = 30, weight_missing = 0.5)
#> `protein_Id`: columns `proteinID`, `idtype2` united with separator '~'.
#> creating sampleName from file_name column
#> setup_analysis: dropped 5 unconfigured columns: average_prot_abundance, sd, mean, N, Replicate.
#> setup_analysis: added 89 rows with NA response for feature and sample combinations absent from the input.
lfqdata <- LFQData$new(istar$data, istar$config)
lfqdata$rename_response("transformedIntensity")
strat <- strategy_lm(paste(lfqdata$response(), "~ group_"))
mod <- build_model_impute(lfqdata, strat)
#> fit (ModelImputed): 6 refit at the limit of detection (e.g. DuwH7n~2082, HvIpHG~1448, JcKVfU~4958, JfvT8X~6972, LlQY7I~3486, ...): fit failed, singular or missing a group; missing responses imputed at the LOD
#> fit (ModelImputed): 44 missing responses dropped (e.g. 0m5WN4~6730, 7QuTub~6175, 7cbcrd~2687, 9VUkAq~3402, BEJI92~2727, ...): NA response (missing observation) left out of the fit
#> See $provenance().
```

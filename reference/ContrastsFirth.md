### `ContrastsFirth$new()`

initialize create Contrast

#### Usage

    ContrastsFirth$new(
      model,
      contrasts,
      p.adjust = prolfqua::adjust_p_values,
      model_name = "firth"
    )

#### Arguments

- `model`:

  a dataframe with a structure similar to that generated by
  [`build_model`](https://fgcz.github.io/prolfqua/reference/build_model.md)

- `contrasts`:

  a character vector with contrast specification

- `p.adjust`:

  function to adjust the p-values

- `model_name`:

  name of contrast method, default firth

------------------------------------------------------------------------

### `ContrastsFirth$get_contrast_sides()`

get both sides of contrasts

#### Usage

    ContrastsFirth$get_contrast_sides()

------------------------------------------------------------------------

### `ContrastsFirth$get_linfct()`

get linear functions from contrasts

#### Usage

    ContrastsFirth$get_linfct(avg = TRUE)

#### Arguments

- `avg`:

  logical TRUE - get also linfct for averages

#### Returns

the linfct-annotated copy of the model container (`model_df`,
`strategy`); the shared input model is left untouched.

------------------------------------------------------------------------

### `ContrastsFirth$get_contrasts()`

get table with contrast estimates

#### Usage

    ContrastsFirth$get_contrasts(all = FALSE)

#### Arguments

- `all`:

  should all columns be returned (default FALSE)

#### Returns

data.frame with contrasts

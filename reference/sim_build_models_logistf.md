# build dataframe with models for testing

build dataframe with models for testing

## Usage

``` r
sim_build_models_logistf(
  model = c("parallel2", "parallel3", "factors", "interaction"),
  Nprot = 10,
  with_missing = TRUE,
  weight_missing = 1,
  peptide = FALSE
)
```
